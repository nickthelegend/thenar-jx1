# JX1 Modular Actuator Interface (MAI) — v0.3

The MAI lets any actuator that fits a class envelope drop into the JX1 structure without redesigning links. CAD: every
class exists as a native parametric stator/rotor pair in `CAD/Actuators/` (`JX1_ACT_<class>_Housing` / `_Output`),
generated by `tools/cad/build_actuators.py` from `tools/cad/params.py`. Brackets reference only MAI features.

## 1. Frame and datums (all classes)

| Datum | Definition | CAD feature |
|---|---|---|
| Joint axis | +Z of the actuator frame, pointing out of the output face | `AX_Joint` (both parts) |
| Interface plane | housing/output split plane, z = 0 | `Front Plane` (both parts) |
| Output mounting face | z = +T_OUT (child link bolts here) | `PL_Mount` (output) |
| Rear mounting face | z = −L_HOUSING (parent link bolts here) | `PL_Rear` (housing) |
| Clocking reference | +X of the actuator frame; connector zone on +Y | `Top Plane` / `Right Plane` |
| Alignment | output pilot boss Ø PILOT_D × PILOT_H mates into an H7 recess (Ø+0.3 mm, +0.2 mm deep) in the child link | `Pilot_Boss` |

Joint-limit mates in assemblies use housing `Right Plane` vs output `Top Plane` with `AX_Joint` as reference direction
(SolidWorks value = 90° + output rotation about +Z_housing). Connector zones are clocked to face −X (backwards) in the leg.

## 4. Mechanical rules for brackets

1. The parent link clamps the **rear face** (M3/M4/M5 through-bolts into the housing threads, max thread engagement per vendor).
2. The child link bolts to the **output face** and centres on the pilot boss; no radial load path through bolts alone.
3. Keep ≥ 2 mm clearance to the housing cylinder and ≥ 3 mm to the connector zone over the full joint range (checked by
   `tools/cad/verify_leg_motion.py`).
4. Cable exit: connector zone faces −X; leave a 25 mm service loop envelope behind every actuator.
5. Replacement: every actuator is removable with its two bolt circles only (no link disassembly beyond the adjacent bracket).
