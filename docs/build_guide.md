# JX1 build guide — what to buy, machine and print, and in what order (v0.4, 2026-09-24)

Nothing has been built yet. This guide turns the verified design into a build sequence. Labels as everywhere in the repo:
VERIFIED / MEASURED / CALCULATED / ESTIMATED / ASSUMED / UNVERIFIED.

## 1. The short version

- **Do not 3D-print the leg or pelvis structure** — not in PETG, not in PA-CF. The printed versions failed the strength
  analysis by a wide margin (table below); the load path is aluminium and steel.
- **Do print** full-size PETG *fit-check* copies of the metal parts first, bolt them to the real actuators, and only then
  order metal. The actuator bolt circles and pilots in the CAD are still ASSUMED (open issue OI-1).
- **Print for real** only the lightly loaded parts: head shell, covers, battery box (PETG-CF); neck bracket, gripper
  (PA-CF, TPU pads).
- The torso and arms are 6061 plate too: the FEA checked every upper-body part both ways — aluminium passes, every PA-CF
  print variant fails (SF 0.12–0.70). The upper arm was thickened after its first check (10/8 mm plates + gussets).

## 2. Why the legs cannot be printed (CALCULATED, `calculations/results/structural/`)

Voxel FEA validated against closed-form cases, loads = every actuator at its peak torque during a 3 BW landing (static)
and fast-walk loads for 1e7 cycles (fatigue); arm parts: actuator-capped shoulder/elbow moments + 75 N (3 g on arm and
1 kg payload). Required safety factor: 2.0 printed, 1.5 aluminium. Printed values: variant studies on the first-iteration
leg geometry, and the final CAD geometry evaluated as PA-CF (upper body; range over print orientations).

| Part | Printed PA-CF (static / fatigue) | Aluminium, final CAD (static / fatigue) |
|---|---|---|
| Hip-yaw bracket | 0.08 / 0.07 | 7075-T6: 1.77 / 1.58 |
| Hip-roll bracket | 0.35 / 0.37 | 6061-T6: 2.76 / 3.80 |
| Thigh | — | 6061-T6: 2.31 / 2.78 |
| Shin | 0.35 / 0.43 | 6061-T6: 3.37 / 4.17 |
| Foot | 0.74 / 0.33 | 6061-T6: 3.50 / 2.03 (lightening hole moved off the clevis; 1.48 fatigue before) |
| Pelvis | 0.90 / 0.73 | 6061-T6: 2.90 / 3.44 |
| Torso frame | 0.70 / 0.42 | 6061-T6: 4.44 / 3.59 |
| Shoulder-pitch bracket | 0.24–0.41 / 0.15–0.25 | 6061-T6: 2.17 / 1.75 |
| Shoulder-roll bracket | 0.23–0.36 / 0.14–0.21 | 6061-T6: 2.05 / 1.66 |
| Upper arm | 0.73–1.23 / 0.44–0.74 | 6061-T6, 10/8 mm + gussets: 5.99 / 4.84 (6 mm version failed: 1.34 / 1.08) |

PA-CF (eSUN ePA-CF, 84 MPa in-layer, 6.5 GPa) is stronger and stiffer than PETG, so PETG parts would be worse still; PETG
also creeps under the constant load of a standing robot.

## 4. Printing notes

- **Fit-check copies (PETG, `manufacturing/fit_check/*_FITCHECK.stl`)**: plain PETG, 0.2 mm layers, 3 walls, 15 % infill.
  Use them to check hole positions, pilots, clearances, rod-end travel and cable routes on the real actuators with the leg
  off the ground. Never load them. FDM holes print slightly undersize — drill them to size for the check.
- **PA-CF parts**: dry the filament before printing, use a hardened nozzle, print load-bearing plates up to 10 mm fully
  solid (≥ 6 perimeters), 100 % infill within 8 mm of every bolt hole, metal washers ≥ 2.5 d under bolt heads
  (`calculations/structural/materials.yaml`).

## 5. Buying (prices from `bom/master_bom.csv`, INR incl. GST/duty where stated)

- Actuators are 77 % of the robot (₹5,45,998). Phase 1 (legs) needs 12: 4× RS04 (hip pitch, knee), 2× RS03 (hip roll),
  6× RS06 (hip yaw, ankle motors) = ₹3,70,788. Phase 2 adds RS06 (waist), 4× RS02, 4× RS00 = ₹1,75,210.
  The same units through a China distributor would save ≈ ₹1,87,074 (see `bom/cost_summary.md`).
- Metal leg + pelvis set: ≈ ₹42,600 ESTIMATED from job-shop hourly rates — get real quotes (OI-12) with the STEP + PDF set
  (Robocon CNC, Makenica, or a local laser/CNC shop).
- Bench items first: Waveshare USB-CAN-A adapter (₹2,189), a current-limited bench supply, one actuator of each class.

## 6. Build order

1. **Lock the actuator interfaces (OI-1).** Get the official RobStride STEP files (or measure one unit of each class),
   put the bolt-circle diameters, thread sizes and pilot diameters into `tools/cad/params.py`, and rebuild the CAD
   (README → *Reproduce*). The CAD is parametric: a rebuild, not a redraw. Re-run the verification and FEA.
2. **Bench electronics** (`docs/electrical_wiring.md` §6): one actuator on the USB-CAN adapter — set its CAN ID, read
   feedback and fault flags; then the Teensy hub firmware (`firmware/hub/jx1_hub`) with one bus populated; E-stop test.
3. **Fit-check prints** on the real actuators (section 4). Fix anything found, rebuild, re-export.
4. **Order metal** with the updated STEP/PDF set; order the phase-1 actuators.
5. **One leg on a clamp stand**: single-joint tests at low gains, set zero offsets, check every joint limit against
   `simulation/joint_map.yaml` and every motor sign against the firmware config (`config_hub_a.h` / `config_hub_b.h`,
   derived from the CAD).
6. **Both legs + pelvis on a lifting gantry with a chest harness** (`docs/safety_architecture.md` §6): damping mode →
   PD stand (gains from `tools/sim/build_robot_description.py`, KP/KD tables) → weight shifts → slow walking with the
   gait validated in MuJoCo (`simulation/mujoco/walk_jx1.py`).
7. **Phase 2 upper body**: torso frame, battery, Jetson and hub board, arms (all 6061 plate), head and camera.
